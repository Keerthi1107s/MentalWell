# MentalWell

A self-contained, responsive mental health awareness and helpline directory website for a college mini project.

## Run locally

Open `index.html` in a browser, or serve this folder with a local web server, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Included

- Mental health awareness topic guides
- India helpline directory with verified government-source links and clearly marked demo entries
- Student well-being and self-care tools
- Resource search, category filters, and locally saved bookmarks
- Responsive navigation, dark mode, and accessibility support

The contact form is a front-end demonstration. It does not send or store messages. The site provides information only and is not a substitute for professional care.
